## 🌟 Key Features & Architectural Highlights

1. **Award-Caliber Visual Design & Materiality (Awwwards / FWA Standard)**:
   - **Obsidian Dark Surface Architecture** (`#05070B` & `#0A0D14`) with 1px hairline borders (`border-white/[0.08]`), specular gradient glows, and dynamic cursor spotlight tracking.
   - **Bespoke Typography**: Architectural `Syne` headlines, editorial `Plus Jakarta Sans` body copy, and precision `JetBrains Mono` telemetry labels.
   - **Zero Generic AI Clichés**: No rainbow gradient headlines, no artificial eyebrow badge spam, and no fake testimonial cards. Grounded in actual engineering rigor and production telemetry.

2. **Real-Time 3D WebGL Synaptic Mesh (`ThreeHeroCanvas.tsx`)**:
   - Built with Three.js WebGL: 42 dynamic neural agent nodes connected by ambient bezier splines.
   - Procedural data packets traversing synaptic pathways with mouse parallax damping and camera easing.
   - Optimized with `IntersectionObserver` to automatically pause rendering when off-screen for 60fps thermal efficiency and minimal battery footprint.

3. **Procedural Web Audio API Sound System (`sound.ts`)**:
   - Zero-dependency client-side audio synthesizer generating micro-tonal haptic audio cues:
     - `playHover`: 920Hz subtle harmonic ping
     - `playClick`: 480Hz tactile feedback pulse
     - `playNodeStep`: Multi-step chord progression during pipeline execution
     - `playSuccess`: High-frequency celebration chord on human-in-the-loop approvals
   - Mute state persistence in `localStorage` with interactive animated equalizer bars in the dock navbar.

4. **Interactive Enterprise Workflow Simulator (`InteractiveWorkflowRunner.tsx`)**:
   - Live simulation across 3 real-world production scenarios:
     - `01. B2B Inbound Lead Intelligence & Triage`
     - `02. Multimodal PO & Commercial Invoice Extraction`
     - `03. SOP & Compliance Knowledge Copilot`
   - Real-time step-by-step node execution, latency counters, payload packet inspector, and **Human-in-the-Loop decision approval gate**.

5. **Architecture Blueprint Playgrounds (`BlueprintShowcase.tsx`)**:
   - **KB / 01 Knowledge Copilot**: Citation tracing with confidence scores and source document references.
   - **DOC / 02 Document Intelligence**: Automated PO invoice extraction with exception highlighting.
   - **AI / 03 Multi-Model Routing Gateway**: Real-time policy switching between Low Latency, Balanced Intelligence, and Deep Reasoning.

6. **Automation ROI Liberation Calculator (`RoiCalculator.tsx`)**:
   - Dynamic parameter sliders calculating annual hours liberated and financial capital recovered in real time.

7. **Global Model Matrix (`ModelGatewayMatrix.tsx`)**:
   - In-depth telemetry and benchmarks across 12+ foundation models (OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet / 3.7, Google Gemini 2.5 Flash, DeepSeek-R1, Qwen 2.5, Llama 3.3, Mistral, Grok) with live category filtering.

8. **Zero-Latency Dual-Language Engine (English / 简体中文)**:
   - Full bilingual parity across all pages, interactive sandboxes, telemetry metadata, and forms with zero page reload.

## 🛠️ Tech Stack & Engineering Rigor

- **Framework**: React 18 + TypeScript + Vite
- **3D Graphics**: Three.js (WebGL Canvas)
- **Audio Engine**: Web Audio API (procedural oscillator synthesis)
- **Styling**: Tailwind CSS with custom design tokens (`tailwind.config.js`)
- **Icons**: Lucide React
- **Performance**: Code-split bundle with manual chunking (`three`, `vendor`, `index`), responsive asset loading, sub-100ms TTI.

```bash
# Clone the repository

pnpm run build
```
